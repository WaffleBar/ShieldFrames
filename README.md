# ShieldFrames

> **Discontinued.** Development has stopped. This addon is **no longer distributed on WowUp / WowUp Hub**.

Midnight secret-value limits made reliable Blood Shield / combat absorb sizing impractical to maintain. Existing installs will keep working until you remove them; there will be no further updates.

**Author:** Waffle

---

Previously: overshield overlay for Blizzard unit frames (player, target, focus, pet, compact party/raid).

## Remove from your game

1. In **WowUp**: My Addons → right-click **ShieldFrames** → **Remove**
2. Or delete the folder:
   `World of Warcraft\_retail_\Interface\AddOns\ShieldFrames`
